# 🃏 جدول امتیاز حکم — وب‌اپ آنلاین

تابلوی امتیازات **زنده** و **آنلاین** برای بازی حکم در جمع‌های خانوادگی و دوستانه.
دیگه لازم نیست روی کاغذ بنویسید — همه از هر جا با موبایل جدول رو می‌بینند.

## ✨ امکانات

- ✅ **همگام‌سازی لحظه‌ای** بین همه گوشی‌های متصل (Live Sync با Supabase)
- ✅ **دو سطح دسترسی**: بیننده (فقط تماشا) و ادمین (ثبت امتیاز)
- ✅ **کنترل دسترسی سمت سرور** — رمز ادمین فقط سمت سرور بررسی می‌شود و هرگز به صورت خام ذخیره نمی‌شود
- ✅ ستون‌های منطبق بر جدول کاغذی: برد، باخت، حاکم‌کت کرده/شده، مارس کرده/شده و جمع کل
- ✅ **دکمه بازگشت (Undo)** برای ابطال آخرین ثبت اشتباهی
- ✅ **لاگ رویدادها** با ساعت (مثلاً «۲۳:۱۵ — ثبت برد برای عمو جعفر»)
- ✅ **جدول رتبه‌بندی** کامل مثل برگه کاغذی، با تاریخ شمسی
- ✅ **دور/شب جدید** و **آرشیو** نتایج قبلی
- ✅ **PWA** — قابل نصب روی گوشی (Add to Home Screen) و کار آفلاین برای مشاهده
- ✅ رابط کاربری **فارسی/RTL** با فونت وزیرمتن و طراحی موبایل-محور

## 🧰 فناوری‌ها

- **فرانت‌اند**: React + Vite + Tailwind CSS + vite-plugin-pwa
- **بک‌اند/دیتابیس**: Supabase (PostgreSQL + Realtime)
- **کنترل دسترسی**: توابع امن SQL (security definer) + RLS

## 🚀 راه‌اندازی قدم‌به‌قدم

### ۱) ساخت پروژه Supabase (رایگان)

1. به [supabase.com](https://supabase.com) بروید و وارد شوید.
2. دکمه **New Project** را بزنید:
   - نام دلخواه (مثلاً `hokm`)
   - یک رمز دیتابیس وارد کنید (کنار بگذارید؛ لازم نمی‌شود)
   - نزدیک‌ترین منطقه (Region) را انتخاب کنید
3. چند دقیقه صبر کنید تا پروژه آماده شود.

### ۲) اجرای اسکیمای دیتابیس

1. در پنل Supabase، از منوی سمت چپ وارد **SQL Editor** شوید.
2. روی **New query** بزنید.
3. کل محتوای فایل [`supabase/schema.sql`](./supabase/schema.sql) را کپی کرده و در آنجا **Paste** کنید.
4. دکمه **Run** (یا `Ctrl+Enter`) را بزنید. باید پیام موفقیت ببینید.

> این اسکیما جداول، امنیت (RLS) و توابع امن ثبت امتیاز را می‌سازد و همگام‌سازی لحظه‌ای را فعال می‌کند.

### ۳) تنظیم کلیدها در پروژه

1. در پنل Supabase از منوی **Project Settings → API** (یا آیکون چرخ‌دنده) دو مقدار را کپی کنید:
   - **Project URL** (مثل `https://abcdefgh.supabase.co`)
   - **anon public** key (یک رشته طولانی)
2. فایل `.env` را در ریشه پروژه باز کنید و مقادیر را جایگزین کنید:

   ```
   VITE_SUPABASE_URL=https://abcdefgh.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6...
   ```

### ۴) اجرا

```bash
# نصب وابستگی‌ها
npm install

# اجرای نسخه توسعه (لوکال)
npm run dev
```

سپس مرورگر را روی `http://localhost:5173` باز کنید.

برای تست با گوشی در همان شبکه WiFi، از آدرس LAN نمایش‌داده‌شده در ترمینال استفاده کنید (چون `host: true` فعال است).

## 🌐 انتشار آنلاین (همه از همه جا دسترسی داشته باشند)

### روش الف — Vercel (ساده‌ترین، رایگان)

1. کد را در یک مخزن GitHub آپلود کنید.
2. در [vercel.com](https://vercel.com) وارد شوید و **Import** کنید.
3. در تنظیمات پروژه، دو متغیر محیطی را اضافه کنید:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. دکمه **Deploy** را بزنید. بعد از چند لحظه یک آدرس عمومی مثل `https://hokm.vercel.app` می‌گیرید.

### روش ب — Netlify

1. پوشه `dist` را بعد از اجرای `npm run build` بسازید.
2. در [netlify.com](https://netlify.com) روی **Add new site → Deploy manually** پوشه `dist` را بکشید و رها کنید.
3. متغیرهای محیطی را در تنظیمات سایت اضافه کنید.

> نکته: چون اپ از URL هش (`#/room/CODE`) استفاده می‌کند، نیازی به تنظیم خاص ریدایرکت نیست.

## 📱 نحوه استفاده

### ساخت اتاق (برای برگزارکننده/ادمین)

1. وارد اپ شوید و **«ساخت اتاق جدید»** را بزنید.
2. یک **کد اتاق ۶ رقمی** (خودکار یا دلخواه) و یک **رمز ادمین** انتخاب کنید.
3. بعد از ساخت، کد اتاق را برای خانواده و دوستان بفرستید (دکمه «کپی» در هدر اتاق).

### ورود بقیه (بیننده)

1. کد اتاق را از شما می‌گیرند.
2. در صفحه اصلی گزینه **«ورود به اتاق»** را می‌زنند و کد را وارد می‌کنند.
3. حالا جدول را **زنده** و لحظه‌ای می‌بینند، ولی امکان تغییر ندارند.

### ثبت امتیاز (فقط ادمین)

- ادمین روی دکمه‌های هر بازیکن تپ می‌زند:
  - **+ برد / − باخت**
  - **+ حاکم‌کت کرده / − حاکم‌کت شده**
  - **+ مارس کرده / − مارس شده**
- جمع کل به صورت خودکار و آنی محاسبه می‌شود.
- اگر ثبت اشتباهی شد، دکمه **«↶ بازگشت آخرین»** در نوار بالا آخرین امتیاز را برمی‌گرداند.

### مدیریت بازیکنان و دورها (ادمین)

- **«＋ افزودن بازیکن»**: اضافه کردن بازیکن جدید.
- **«↻ دور جدید»**: شروع شب/دور جدید؛ جدول فعلی در آرشیو ذخیره می‌شود.
- در تب **«تاریخچه»**: لاگ رویدادها + آرشیو دورهای قبلی + امکان پاک/حذف دور.

### برای اینکه دو نفر ادمین باشند

کافی است هر دو نفر **همان رمز ادمین** را در گوشی خود وارد کنند (دکمه «ورود ادمین»). هر دو می‌توانند امتیاز ثبت کنند.

## 🔐 درباره امنیت

- رمز ادمین به صورت **هش bcrypt** در دیتابیس ذخیره می‌شود (خودِ رمز هرگز).
- هیچ عملیات نوشتنی مستقیم نیست؛ همه از طریق **توابع SQL امن** انجام می‌شود که رمز را **سمت سرور** بررسی می‌کنند.
- حتی اگر کسی کلید `anon` را از کد جاوااسکریپت پیدا کند، **بدون رمز ادمین نمی‌تواند** امتیازی ثبت یا حذف کند.
- جدول اتاق‌ها (که شامل هش رمز است) برای کلاینت قابل خواندن مستقیم نیست.

## ❓ سوالات متداول

**سوال: اگر رمز ادمین را فراموش کنم چه؟**
در SQL Editor پروژه Supabase این دستور را اجرا کنید (کد اتاق را جایگزین کنید):
```sql
update public.rooms
set admin_password_hash = extensions.crypt('رمز-جدید-خود', extensions.gen_salt('bf', 10))
where code = 'کداتاق';
```

**سوال: چند نفر همزمان می‌توانند استفاده کنند؟**
هر تعداد. پلن رایگان Supabase برای جمع‌های خانوادگی کاملاً کافی است.

**سوال: اینترنت قطع شد، امتیازها از بین می‌رود؟**
خیر. ادمین می‌تواند بعد از وصل شدن دوباره ثبت کند؛ بیننده‌ها هم با اتصال مجدد خودکار همگام می‌شوند. کش PWA هم اپ را سریع باز می‌کند.
